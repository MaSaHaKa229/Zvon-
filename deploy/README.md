# Zvon на своём сервере (VPS)

В этом варианте сервер Zvon постоянно работает на арендованном сервере в интернете. Всем участникам нужно только приложение. VPN, проброс портов и «хост», который должен держать компьютер включённым, не нужны.

Инструкция рассчитана на человека, который никогда не работал с серверами. Команды копируйте целиком.

---

## 1. Какой сервер арендовать

Нужен **VPS** (виртуальный сервер) с такими параметрами:

| Параметр | Сколько нужно |
|---|---|
| Система | **Ubuntu 24.04** или 22.04 |
| Процессор | 1–2 ядра (2 — если часто показываете экран) |
| Память | 1–2 ГБ |
| Диск | от 20 ГБ (файлы чата хранятся здесь) |
| IP-адрес | **публичный IPv4** (обычно входит в тариф) |
| Канал | от 100 Мбит/с, трафик безлимитный или от 1 ТБ в месяц |

Выбирайте расположение сервера поближе к участникам: чем ближе, тем меньше задержка голоса.

Сколько тратится трафика: голос — примерно 0,05 Мбит/с на каждого слушателя от каждого говорящего. 10 человек в одном канале — около 5 Мбит/с. Демонстрация экрана — 2–4 Мбит/с на каждого зрителя.

После покупки в панели хостинга будут **IP-адрес** сервера и **пароль root** (или вход по SSH-ключу). Запишите их.

## 2. Подключиться к серверу

- **Windows 10/11:** откройте «Пуск» → наберите `PowerShell` → откройте.
- **macOS:** откройте «Терминал».

Введите (вместо `203.0.113.10` — IP вашего сервера):

```bash
ssh root@203.0.113.10
```

На вопрос `Are you sure you want to continue connecting` напишите `yes` и нажмите Enter. Потом введите пароль root. Символы при вводе пароля не отображаются, это нормально.

Все команды дальше выполняются на сервере, в этом окне.

## 3. Установить Docker

```bash
curl -fsSL https://get.docker.com | sh
```

Установка занимает 1–2 минуты.

## 4. Скачать Zvon

```bash
apt-get install -y git
git clone https://github.com/MaSaHaKa229/Zvon-.git zvon
cd zvon/deploy
```

> Если репозиторий закрытый (private), git попросит логин и пароль. Вместо пароля нужен токен GitHub: github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens → доступ «Contents: Read» к этому репозиторию.

## 5. Настроить

Создайте файл настроек из примера:

```bash
cp .env.example .env
```

Придумайте ключ администратора. Эта команда выведет случайную строку, скопируйте её:

```bash
openssl rand -hex 24
```

Откройте настройки в редакторе:

```bash
nano .env
```

Поменяйте:

- `ZVON_NAME`: название сервера;
- `ZVON_PASSWORD`: пароль для входа. **Обязательно задайте** и дайте его только друзьям;
- `ZVON_ADMIN_TOKEN`: вставьте строку из `openssl rand -hex 24`. Никому её не давайте.

Остальное можно не трогать. Чтобы сохранить файл, нажмите `Ctrl+O`, затем Enter. Чтобы выйти из редактора, нажмите `Ctrl+X`.

## 6. Открыть порты

На сервере:

```bash
ufw allow 22/tcp
ufw allow 7777/tcp
ufw allow 40000/udp
ufw allow 40000/tcp
ufw --force enable
```

Порт `22` — это ваш доступ по SSH, его закрывать нельзя. `7777` нужен для чата и файлов, `40000` — для голоса и экрана.

> У некоторых хостингов (AWS, Google Cloud, Oracle, Yandex Cloud, VK Cloud и др.) есть **ещё один брандмауэр в панели управления**: «группы безопасности», Security groups, Firewall. Откройте там те же порты: TCP 7777, UDP 40000, TCP 40000.

## 7. Запустить

```bash
docker compose up -d --build
```

Первая сборка занимает 3–5 минут. Проверьте, что сервер запустился:

```bash
docker compose logs --tail 30
```

Там должны быть строки:

- `Медиа слушает порт 40000 … внешний адрес для клиентов: <IP сервера>`, значит голос готов;
- `Отпечаток сертификата …: AB:CD:…`, это «отпечаток» вашего сервера. Пригодится в шаге 8.

Сервер сам запускается после перезагрузки VPS и после сбоев. Окно SSH можно закрыть (команда `exit`).

## 8. Подключиться из приложения

1. Установите Zvon. Нужен **онлайн-вариант** установщика: в GitHub Actions он называется `zvon-online-…`.
2. Введите ник, **адрес сервера** (его IP) и **пароль** из `ZVON_PASSWORD`.
3. При первом подключении появится окно с отпечатком сертификата. Сверьте его с отпечатком из шага 7 и подтвердите. Остальным участникам можно просто подтвердить.
4. **Администратору:** поставьте галочку «Я администратор сервера» и вставьте `ZVON_ADMIN_TOKEN`. Откроется панель управления: каналы, участники, настройки, блокировки.

Чтобы у друзей адрес уже был вписан в приложение: GitHub → репозиторий → Settings → Secrets and variables → Actions → вкладка Variables → New repository variable, имя `ZVON_SERVER`, значение — IP сервера. Затем перезапустите сборку: Actions → Build → Run workflow.

## Обслуживание

Все команды выполняются на сервере в папке `zvon/deploy` (`cd ~/zvon/deploy`).

| Что сделать | Команда |
|---|---|
| Посмотреть логи | `docker compose logs --tail 100` |
| Перезапустить | `docker compose restart` |
| Остановить | `docker compose down` |
| Обновить до новой версии | `git pull && docker compose up -d --build` |
| Изменить настройки | `nano .env`, затем `docker compose up -d` |
| Резервная копия | `tar czf ~/zvon-backup.tar.gz data` |

Все данные (сообщения, файлы, сертификат) лежат в папке `zvon/deploy/data`. **Не удаляйте её.** Если она пропадёт, у всех участников появится предупреждение «Сертификат сервера изменился!» и пропадёт история чата.

## Если что-то не работает

| Что происходит | Что проверить |
|---|---|
| «Хост не отвечает» | Сервер запущен (`docker compose ps`)? Открыт TCP 7777 в `ufw` **и** в панели хостинга? |
| Чат работает, голос висит на «Подключение к голосу…» | Не открыт UDP/TCP 40000, или не определился внешний IP. Посмотрите в логах строку `Медиа слушает порт`. Если там не IP сервера, впишите его в `.env`: `ZVON_ANNOUNCED_IP=203.0.113.10`, затем выполните `docker compose up -d`. |
| «Слишком много неверных паролей» | Сервер блокирует адрес на 15 минут после 10 неверных паролей подряд (защита от подбора). Подождите или перезапустите сервер. |
| Нет панели администратора | Ключ должен совпадать с `ZVON_ADMIN_TOKEN` символ в символ. |

## Без Docker

Нужен Node.js 22. Сервер собирается под обычный Node, не под Electron:

```bash
npm ci --ignore-scripts && npm rebuild better-sqlite3 mediasoup
npx electron-vite build
ZVON_DATA=./data ZVON_PASSWORD=… ZVON_ADMIN_TOKEN=… ZVON_ANNOUNCED_IP=auto node out/main/server.js
```

Все параметры из `.env.example` можно передать и флагами: `--password`, `--admin-token`, `--announced-ip`, `--port`, `--rtc-port`, `--max-upload-mb`, `--name`, `--data`.
