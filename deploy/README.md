# Zvon на своём сервере (VPS)

В этом варианте сервер Zvon постоянно работает на арендованном сервере в интернете. VPN, проброс портов и «хост», который должен держать компьютер включённым, не нужны.

Подключаться можно двумя способами:
- **из браузера** на компьютере или телефоне: открыть `https://ваш-адрес`, ничего не устанавливая;
- **из приложения** Zvon для Windows, macOS или Linux.

Инструкция рассчитана на человека, который никогда не работал с серверами. Команды копируйте целиком.

---

## 1. Какой сервер арендовать

Нужен **VPS** (виртуальный сервер) с такими параметрами:

| Параметр | Сколько нужно |
|---|---|
| Система | **Ubuntu 24.04** или 22.04 |
| Процессор | 1–2 ядра (2 — если часто показываете экран) |
| Память | 1–2 ГБ |
| Диск | от 20 ГБ (файлы чата хранятся здесь) |
| IP-адрес | **публичный IPv4** (обычно входит в тариф) |
| Канал | от 100 Мбит/с, трафик безлимитный или от 1 ТБ в месяц |

Выбирайте расположение сервера поближе к участникам: чем ближе, тем меньше задержка голоса.

Сколько тратится трафика: голос — примерно 0,05 Мбит/с на каждого слушателя от каждого говорящего. 10 человек в одном канале — около 5 Мбит/с. Демонстрация экрана — 2–4 Мбит/с на каждого зрителя.

После покупки в панели хостинга будут **IP-адрес** сервера и **пароль root** (или вход по SSH-ключу). Запишите их.

## 2. Подключиться к серверу

- **Windows 10/11:** откройте «Пуск» → наберите `PowerShell` → откройте.
- **macOS:** откройте «Терминал».

Введите (вместо `203.0.113.10` — IP вашего сервера):

```bash
ssh root@203.0.113.10
```

На вопрос `Are you sure you want to continue connecting` напишите `yes` и нажмите Enter. Потом введите пароль root. Символы при вводе пароля не отображаются, это нормально.

Все команды дальше выполняются на сервере, в этом окне.

## 3. Установить Docker

```bash
curl -fsSL https://get.docker.com | sh
```

Установка занимает 1–2 минуты.

## 4. Скачать Zvon

```bash
apt-get install -y git
git clone https://github.com/MaSaHaKa229/Zvon-.git zvon
cd zvon/deploy
```

> Если репозиторий закрытый (private), git попросит логин и пароль. Вместо пароля нужен токен GitHub: github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens → доступ «Contents: Read» к этому репозиторию.

## 5. Настроить

Создайте файл настроек из примера:

```bash
cp .env.example .env
```

Откройте настройки в редакторе:

```bash
nano .env
```

Поменяйте:

- `ZVON_NAME`: название сервера;
- `ZVON_ADMIN_LOGIN` и `ZVON_ADMIN_PASSWORD`: логин и пароль администратора (вас). Пароль придумайте длинный, не короче 6 символов. Этот аккаунт создаётся при первом запуске, остальных участников вы заведёте сами в приложении (шаг 8);
- `ZVON_DOMAIN`: адрес веб-версии. Если своего домена нет, впишите IP сервера через дефисы и добавьте `.sslip.io`. Например, для IP `203.0.113.10` получится `203-0-113-10.sslip.io`: это бесплатный сервис, адрес начинает работать сразу. Если домен есть, впишите его (например, `zvon.example.ru`) и в настройках домена создайте запись типа **A** с IP сервера.

Остальное можно не трогать. Чтобы сохранить файл, нажмите `Ctrl+O`, затем Enter. Чтобы выйти из редактора, нажмите `Ctrl+X`.

## 6. Открыть порты

На сервере:

```bash
ufw allow 22/tcp
ufw allow 80/tcp
ufw allow 443/tcp
ufw allow 443/udp
ufw allow 7777/tcp
ufw allow 40000/udp
ufw allow 40000/tcp
ufw --force enable
```

Порт `22` — это ваш доступ по SSH, его закрывать нельзя. `80` и `443` нужны для веб-версии (через них же выдаётся сертификат HTTPS), `7777` — для чата и файлов в приложении, `40000` — для голоса и экрана.

> У некоторых хостингов (AWS, Google Cloud, Oracle, Yandex Cloud, VK Cloud и др.) есть **ещё один брандмауэр в панели управления**: «группы безопасности», Security groups, Firewall. Откройте там те же порты: TCP 80, TCP и UDP 443, TCP 7777, UDP и TCP 40000.

## 7. Запустить

```bash
docker compose up -d --build
```

Первая сборка занимает 3–5 минут. Проверьте, что сервер запустился:

```bash
docker compose logs --tail 30
```

Там должны быть строки:

- `Медиа слушает порт 40000 … внешний адрес для клиентов: <IP сервера>`, значит голос готов;
- `Отпечаток сертификата …: AB:CD:…`, это «отпечаток» вашего сервера. Пригодится в шаге 8.

Сервер сам запускается после перезагрузки VPS и после сбоев. Окно SSH можно закрыть (команда `exit`).

Через минуту после запуска откройте в браузере `https://` и ваш `ZVON_DOMAIN`, например `https://203-0-113-10.sslip.io`. Должен появиться экран входа Zvon. Если браузер пишет об ошибке сертификата, подождите ещё минуту: сертификат получается при первом запуске. Посмотреть, как идёт получение сертификата: `docker compose logs caddy --tail 30`.

## 8. Подключиться

### Из браузера (компьютер или телефон)

1. Откройте `https://ваш-ZVON_DOMAIN` в Chrome, Edge, Firefox или Safari.
2. Введите **логин и пароль**, которые выдал администратор, и нажмите «Подключиться». Когда войдёте в голосовой канал, разрешите доступ к микрофону.
3. **На телефоне** приложение можно добавить на главный экран, и оно будет открываться как обычное. Android (Chrome): меню ⋮ → «Добавить на главный экран». iPhone (Safari): кнопка «Поделиться» → «На экран „Домой“».

Ограничения браузера:
- на телефоне нельзя показывать свой экран, но смотреть чужую демонстрацию можно;
- кнопка рации (push-to-talk) работает, только пока вкладка Zvon открыта и активна;
- на iPhone звук прерывается, если свернуть браузер или заблокировать экран.

### Из приложения

1. Установите Zvon. Нужен **онлайн-вариант** установщика: в GitHub Actions он называется `zvon-online-…`.
2. Введите **адрес сервера** (`ZVON_DOMAIN` с портом 443, например `203-0-113-10.sslip.io:443`, или IP сервера), **логин и пароль**.
3. Если вы подключаетесь по IP, при первом подключении появится окно с отпечатком сертификата. Сверьте его с отпечатком из шага 7 и подтвердите. По адресу `ZVON_DOMAIN:443` такого окна нет: сертификат там настоящий.

### Аккаунты участников

1. Войдите под логином администратора (`ZVON_ADMIN_LOGIN`).
2. Нажмите на название сервера слева вверху → **«Панель хоста»** → вкладка **«Аккаунты»**.
3. Впишите логин (латиницей) и начальный пароль, нажмите **«Создать»** и передайте их человеку.
4. Ник, аватарку и пароль человек меняет сам: нажать на свой ник внизу слева → «Профиль». На телефоне сначала нажмите ☰.

Там же можно задать новый пароль, если его забыли, выдать или снять права администратора, отключить или удалить аккаунт.

Чтобы у друзей адрес уже был вписан в приложение: GitHub → репозиторий → Settings → Secrets and variables → Actions → вкладка Variables → New repository variable, имя `ZVON_SERVER`, значение — IP сервера. Затем перезапустите сборку: Actions → Build → Run workflow.

## Переход на аккаунты (если сервер уже работал со старой версией)

1. Подключитесь к серверу по SSH и перейдите в папку: `cd ~/zvon/deploy`.
2. Скачайте новую версию: `git pull`.
3. Откройте настройки: `nano .env`. Удалите строки `ZVON_PASSWORD` и `ZVON_ADMIN_TOKEN` и добавьте:
   ```
   ZVON_ADMIN_LOGIN=admin
   ZVON_ADMIN_PASSWORD=ваш-длинный-пароль
   ```
4. Пересоберите и запустите: `docker compose up -d --build`.
5. Войдите под этим логином и создайте аккаунты участникам (см. «Аккаунты участников»).
6. Участникам с приложением для компьютера нужно установить новую версию. Старая подключиться не сможет: изменился протокол.

История чата и файлы сохраняются. Старые сообщения остаются подписаны прежними никами. Аккаунты — это новые пользователи, поэтому прежние участники не появятся в списке «не в сети».

## Обслуживание

Все команды выполняются на сервере в папке `zvon/deploy` (`cd ~/zvon/deploy`).

| Что сделать | Команда |
|---|---|
| Посмотреть логи | `docker compose logs --tail 100` |
| Перезапустить | `docker compose restart` |
| Остановить | `docker compose down` |
| Обновить до новой версии | `git pull && docker compose up -d --build` (после обновления сверьте свой `.env` с `.env.example`: там могли появиться новые настройки) |
| Изменить настройки | `nano .env`, затем `docker compose up -d` |
| Резервная копия | `tar czf ~/zvon-backup.tar.gz data` |

Все данные (сообщения, файлы, сертификат) лежат в папке `zvon/deploy/data`. **Не удаляйте её.** Если она пропадёт, у всех участников появится предупреждение «Сертификат сервера изменился!» и пропадёт история чата.

## Если что-то не работает

| Что происходит | Что проверить |
|---|---|
| Веб-версия не открывается или ошибка сертификата | Открыты TCP 80 и 443 в `ufw` **и** в панели хостинга? `ZVON_DOMAIN` указывает на IP сервера? Логи: `docker compose logs caddy --tail 50`. |
| «Хост не отвечает» | Сервер запущен (`docker compose ps`)? Открыт TCP 7777 в `ufw` **и** в панели хостинга? |
| Чат работает, голос висит на «Подключение к голосу…» | Не открыт UDP/TCP 40000, или не определился внешний IP. Посмотрите в логах строку `Медиа слушает порт`. Если там не IP сервера, впишите его в `.env`: `ZVON_ANNOUNCED_IP=203.0.113.10`, затем выполните `docker compose up -d`. |
| «Слишком много неверных паролей» | Сервер блокирует адрес на 15 минут после 10 неверных паролей подряд (защита от подбора). Подождите или перезапустите сервер. |
| Забыли пароль администратора | Впишите новый в `ZVON_ADMIN_PASSWORD`, поставьте `ZVON_ADMIN_RESET_PASSWORD=1`, выполните `docker compose up -d`, войдите, затем верните `0` и снова `docker compose up -d`. |
| «На этом сервере вход по логину и паролю. Обновите приложение» | Старая версия приложения. Установите новую или зайдите через браузер. |

## Без Docker

Нужен Node.js 22. Сервер собирается под обычный Node, не под Electron:

```bash
npm ci --ignore-scripts && npm rebuild better-sqlite3 mediasoup
npx electron-vite build
ZVON_DATA=./data ZVON_ADMIN_LOGIN=admin ZVON_ADMIN_PASSWORD=… ZVON_ANNOUNCED_IP=auto node out/main/server.js
```

Все параметры из `.env.example` можно передать и флагами: `--admin-login`, `--admin-password`, `--announced-ip`, `--port`, `--rtc-port`, `--max-upload-mb`, `--name`, `--data`.
